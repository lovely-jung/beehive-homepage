# 00 브리프 — 비하이브 홈페이지 분야별 커리큘럼 재설계

## 목적
비하이브(초·중·고 AI·SW·진로·융합 교육, 교원 연수 업체) 홈페이지의 분야 페이지(program.html?cat=)와 수업 상세(course.html?id=)에 올라갈 수업 소개 데이터를 하위 카테고리에 딱 맞게 다시 설계한다.
홈페이지는 학교·기관 담당자가 보고 "이 수업 의뢰하고 싶다"고 느끼게 하는 소개용이다. 상세 교안(발문, 활동지)은 올리지 않는다.

## 사용 스킬(3개를 결합)
- course-design-team: 자료수집·분석 → 수업설계 → 총괄검수 (PPT 단계는 이번엔 제외: 결과물이 홈페이지 데이터)
- creative-lesson-architect: 사례 6개 이상 서칭 → 흔한 패턴/빌려올 메커니즘 → 설계 → 활동성 감독(대상별 활동 비율) → 참신성(뻔함 블랙리스트 교체, 차시마다 훅) → 비판 검토
- lesson-planner: 실습 완주 가능성, 계정·로그인 시간 고려, 무료 툴 한도 확인, 대상별 눈높이, AI 반복 표현 금지

## 카테고리 구조 (cat / sub id — 이 값에서만 고른다)
- ai: basics(AI 기초), literacy(AI 리터러시 · 윤리), genai(생성형 AI 활용)
- sw: physical(아두이노 · 피지컬 컴퓨팅), coding(코딩 기초)
- career: credit(고교학점제 · 자유학기), explore(진로 탐색 · 체험), major(학과 · 전공 탐색), startup(AI 창업 · 해커톤), camp(진로 캠프)
- conv: reading(AI 독서), finance(AI 금융 · 경제), science(AI 과학 · MBL)
- teacher: ai-class(AI 수업 활용), guidance(진로 · 학업 지도)
※ biz(기업·공공기관)는 이번 범위 아님.

## 건드리지 말 것 (실제 운영 수업, sample:false)
- sw-arduino(아두이노 기초), conv-mbl(스트로보스코프 MBL 캠프). 내용 유지. 다른 수업과 내용이 겹치지 않게만 설계.

## 가정
- 툴: 무료 요금제 기준. 학생 연령 가입 제한(예: 만 13세/14세 미만 생성형 AI 가입 불가)을 반드시 반영 — 초등은 교사 시연·계정 불필요 도구(티처블 머신, 엔트리, 오토드로우 등) 중심.
- 시간 기본값: 초 40분, 중 45분, 고 50분, 교원 연수 3시간 특강 / 15시간 직무연수.
- 대상 levels: elem 초등 / mid 중등 / high 고등 / univ 대학 / adult(=교원 연수에서만 '교원'으로 표시). 맞지 않는 대상은 빼도 된다.
- 새로 설계한 수업은 모두 sample: true (아직 운영 전).

## 데이터 형식 (assets/data/courses.js 의 BH_COURSES 항목)
{ id: '<cat>-<영문슬러그>', cat, sub, sample: true, also?: [{cat, sub}],
  title, summary(활동이 보이는 한 문장),
  format: ['정규 수업 (N차시)' | '특강' | '캠프' | '연수' ...], prep: '기기·공간·재료(비하이브 준비 여부)',
  safety?: ['…'] (몸·도구·전기 활동이 있으면 필수),
  levels: { elem|mid|high|univ|adult: { goal(한 문장, 측정 가능), time: 'N차시 × 40분', steps: ['1차시 훅 활동명 — 핵심 활동, 활동', ...](차시당 한 줄), tools, output(학생이 실제로 들고 가는 산출물), link: '교과 · 세특' } } }

## 작성 규칙
- 하위 카테고리마다 수업 1~2개. 카테고리 이름과 수업이 바로 맞물려야 한다(예: 'AI 기초'에 윤리 수업 X).
- 같은 분야 안에서 수업끼리, 다른 분야와도 내용이 겹치지 않게.
- steps에는 참신한 훅 활동명이 드러나게. 뻔함 블랙리스트(포스트잇 브레인스토밍, 마인드맵, 포스터·표어, 골든벨/카훗, PPT 조사 발표, 4컷 만화, 모둠토의→대표발표)를 핵심 활동으로 쓰지 않는다.
- 빈말 금지("~의 중요성을 이해한다", "다양한 ~를 탐색한다"). 이모지 금지. 같은 문장 틀 반복 금지.
- 학생 실명·학교명·강사료 등 내부정보 금지. 실제 존재하지 않는 기관 인증·제휴 주장 금지.
- 성취기준 코드는 확실한 것만 설계서에 기록(홈페이지 데이터의 link 필드엔 교과명만).
