# AI 분야 02 — 수업 설계서 (basics / literacy / genai)

설계 원칙
- AI 기초 = 원리(학습 · 인식 · 추론 · 생성). 편향 · 공정성 · 출처 판별은 리터러시로 보내 겹치지 않게 했다.
- 생성형 AI 활용 = 도구를 목적에 맞게 조종하는 기술(챗봇 제작, 프롬프트 실험). 창업 · 해커톤(career), AI 독서 요약 검증(conv-reading), 금융사기 판별(conv-finance), 교원용 활용(teacher-genai)과 활동이 겹치지 않게 했다.
- 연령: 초등은 계정 불필요 도구 + 교사 시연만. 중등 생성형 AI는 교사 계정 시연 또는 모둠당 1대(만 14세 이상 계정 · 학교 허용 계정). 고등은 본인 계정 가능하되 18세 미만 보호자 동의 확인.
- 성취기준 코드는 확실히 대조하지 못해 기록하지 않는다. 홈페이지 link 필드에는 교과명만.

## 1. ai-how — AI 조련사: 데이터로 가르치는 AI (basics)
컨셉 한 줄: 모델을 "만들고 끝"이 아니라, 일부러 속이고 데이터를 줄였다 늘렸다 하며 "데이터가 곧 실력"을 실험으로 증명한다.

| 대상 | 학습목표 | 차시 · 훅 | 왜 뻔하지 않은가 |
|---|---|---|---|
| 초 (2×40) | 두 가지를 구별하는 AI를 만들고, 학습 사진을 바꿔 판단이 달라지는 것을 3번 이상 실험해 기록한다 | 1 "사람 AI" 분류 게임 → 티처블 머신 가위바위보 학습 | 학생 한 명이 AI 역할(예시 카드만 보고 규칙 추리)을 먼저 해 보고 기계로 넘어감 |
| | | 2 AI 헷갈리게 하기 대작전 | 만든 모델을 일부러 틀리게 만드는 것이 미션. 실패를 수집해 다시 가르침 |
| 중 (3×45) | 데이터의 양 · 다양성 · 라벨 오류를 하나씩 바꾸는 통제 실험으로 정확도 변화를 표로 정리한다 | 1 블라인드 분류 배틀 (사람 팀 vs AI 팀) | 같은 사진을 사람과 AI가 겨뤄, 누가 언제 이기는지부터 따짐 |
| | | 2 데이터 다이어트 실험 | 사진 50→20→5장, 라벨 섞기. 변인 하나만 바꾸는 과학 실험 형식 |
| | | 3 다른 모둠 모델 해킹 | 레드팀: 남의 모델을 깨는 입력을 찾고 내 모델은 데이터로 방어 |
| 고 (4×50) | 혼동 행렬로 오류 유형을 분석하고, 오류를 줄일 데이터 수집 계획을 근거와 함께 제시한다 | 1 AI 오답노트 | 맞힌 것 말고 틀린 사례만 모아 유형 분류 |
| | | 2 혼동 행렬 직접 계산 | 교과서 예시가 아닌 우리 모델의 숫자로 정밀도 · 재현율 계산 |
| | | 3 같은 문제, 다른 감각 | 이미지 → 소리 · 자세 모델로 바꿔 입력 방식에 따른 성능 비교 |
| | | 4 데이터 수집 제안서 + 동료 검토 | "무엇을 몇 장 더, 왜"를 숫자 근거로 씀 |

도구 메모: 티처블 머신(계정 불필요, 브라우저 학습). 웹캠 · 마이크 필요. 모델 저장은 교사 Google 계정.

## 2. ai-inside — AI 머릿속 해부 (basics)
컨셉 한 줄: 학생이 결정나무 · 신경망 · 언어 모델 "부품"이 되어, AI가 답을 고르는 계산을 몸과 손으로 재현한다. (AI4K12 표현 · 추론, 학습, 상호작용 개념 대응)

| 대상 | 학습목표 | 차시 · 훅 | 왜 뻔하지 않은가 |
|---|---|---|---|
| 초 (2×40) | 예/아니요 질문으로 답을 좁히는 결정나무를 만들어 친구가 고른 동물을 4번 이하 질문으로 맞힌다 | 1 스무고개 결정나무 (질문 수 줄이기 경쟁) | 나무를 "그리기"가 아니라 질문 수를 줄이는 대결로 다듬음 |
| | | 2 퀵드로우 오답 추리 | AI가 못 맞힌 그림만 모아 AI가 본 단서를 추리, 우리 나무와 비교 |
| 중 (2×45) | 가중치를 바꾸면 판정이 달라지는 과정을 인간 신경망으로 재현하고, 가중치 조정으로 정답률을 높인다 | 1 인간 신경망 릴레이 | 반 전체가 3개 네트워크의 뉴런이 되어 곱하고 더해 판정, 틀리면 가중치 수정 |
| | | 2 다음 단어 맞히기 주사위 게임 | 우리 반 문장으로 빈도표를 만들어 주사위로 문장 생성 → 챗봇이 단어를 "고르는" 원리 |
| 고 (3×50) | 퍼셉트론 학습과 언어 모델의 확률적 생성을 손계산 · 스프레드시트로 재현하고, 생성형 AI의 그럴듯한 오답을 원리로 설명한다 | 1 손으로 돌리는 퍼셉트론 | 가중치 갱신을 직접 계산하며 경계선이 움직이는 것을 그래프로 봄 |
| | | 2 스프레드시트 언어 모델 | 교과서 지문으로 다음 단어 확률표를 만들고 온도값을 바꿔 생성 |
| | | 3 환각 재현 실험 | 우리 모델이 만든 그럴듯한 거짓 문장을 분석해 원인 설명서 작성 |

도구 메모: 대부분 언플러그드 키트(비하이브 준비) + 스프레드시트. 퀵드로우 계정 불필요. 고등 3차시 생성형 AI 비교는 교사 시연.

## 3. ai-literacy — AI 생성물 수사대 (literacy)
컨셉 한 줄: 진짜와 AI 생성물이 섞인 "사건 파일"을 받아 판정하고, 판정만이 아니라 증거를 제출하는 탐정 수업. (금융사기 · 광고 판별은 conv-finance가 다루므로 여기서는 뉴스 · 사진 · 영상 · 글의 출처와 표기에 집중)

| 대상 | 학습목표 | 차시 · 훅 | 왜 뻔하지 않은가 |
|---|---|---|---|
| 초 (2×40) | "누가 · 언제 · 어디서" 3단계 질문으로 사진을 판정하고 근거를 한 가지 이상 말한다 | 1 진짜 사진 vs AI 사진 경매 | O/X 퀴즈 대신 토큰을 걸게 해 판단에 책임이 생김, 이후 단서 찾기 |
| | | 2 공유 전 3초 멈춤 | 친구에게 온 사진 메시지 상황 카드로 공유 여부를 실제로 결정 |
| 중 (2×45) | 역이미지 검색과 옆으로 읽기로 의심 게시물 3건의 출처를 추적해 사건 보고서로 남긴다 | 1 사건 파일 #1 출처 추적 | 검증 도구를 직접 쥐고 원본을 찾아내는 미션 |
| | | 2 두 개의 진실과 하나의 AI | 친구가 낸 문제에 속은 이유를 분석 (반전 구조) |
| 고 (3×50) | 탐지 도구의 한계를 오판률로 확인하고, 과제 · SNS에서 쓸 AI 사용 표기 가이드를 만든다 | 1 가짜를 만든 사람이 찾는다 | 모둠이 직접 만든 가짜 뉴스 카드를 다른 모둠이 판정 (교실 밖 공유 금지) |
| | | 2 탐지기 믿어도 될까 | 사람 글 · AI 글 · 고친 AI 글을 넣어 오판률을 숫자로 측정 |
| | | 3 AI 사용 표기 가이드 | 실제 언론 · 출판 표기 사례를 비교해 우리 반 규칙 문서로 |

도구 메모: 초등은 비하이브 사건 카드 + 교사 화면만. 중등 역이미지 검색은 로그인 없이 가능한 검색 도구 사용, AI 거짓 문장은 교사 시연으로 생성. 고등 가짜 뉴스 카드 생성은 만 14세 이상 계정 또는 교사 계정.

## 4. ai-fairness — AI 재판정 (literacy)
컨셉 한 줄: 편향을 토론으로 배우지 않고 "겪는다". 내가 만든 규칙 · 내가 운영한 채용 AI가 누군가를 밀어내는 장면에서 출발해 규칙과 평가서를 고친다.

| 대상 | 학습목표 | 차시 · 훅 | 왜 뻔하지 않은가 |
|---|---|---|---|
| 초 (2×40) | 우리 반 "AI 짝꿍 배정기" 규칙을 돌려 손해 보는 경우를 찾고 규칙을 1가지 이상 고친다 | 1 AI 짝꿍 배정기 | 학생이 만든 규칙이 곧 알고리즘. 늘 밀려나는 가상 학생 카드를 발견 |
| | | 2 규칙 고치기 재판 | 밀려난 카드 입장의 항의문으로 규칙 수정 후 다시 돌려 비교 |
| 중 (2×45) | AI 채용 게임에서 편향이 생기는 경로를 데이터 흐름으로 설명하고 점검 질문 5개를 만든다 | 1 내가 CEO라면 (Survival of the Best Fit) | 플레이어가 채용 AI를 직접 운영하는 1인칭 체험 |
| | | 2 편향 역추적 | 탈락자 프로필과 학습 데이터 표를 대조해 원인을 증거로 찾음 |
| 고 (3×50) | 학교에 도입될 수 있는 AI 하나를 골라 이해관계자별 영향과 위험 등급을 담은 영향평가서를 쓴다 | 1 사진 한 장 프로파일링 | 가상 인물 사진에서 AI가 추론해 낸 정보 목록을 보고 내 게시물 점검 |
| | | 2 AI 자동 채점 이의신청 재판 | 탈락 학생 · 개발사 · 학교 · 판사 역할 재판. 판결문에 근거 데이터 필수 |
| | | 3 AI 영향평가서 | 출결 얼굴 인식 · 자동 채점 등 실제 도입 가능 사례로 위험 등급 판정 |

도구 메모: Survival of the Best Fit은 계정 불필요 · 영어 → 비하이브 한글 안내지. 고등 1차시 프로파일링은 비하이브가 만든 가상 인물 자료만 쓰고, 학생 본인 · 친구 사진은 넣지 않는다(교사 시연).

## 5. ai-chatbot — 우리 학교 안내 챗봇 제작소 (genai)
컨셉 한 줄: 진짜 질문을 모아서 만들고, 친구들이 일부러 헷갈리게 묻는 "괴롭히기 테스트"를 통과해야 완성되는 챗봇. (Gandalf 레드팀 구조 차용)

| 대상 | 학습목표 | 차시 · 훅 | 왜 뻔하지 않은가 |
|---|---|---|---|
| 중 (3×45) | 질문 30개 이상을 의도별로 학습시키고, 친구 테스트 오답을 2회 이상 고친 챗봇을 완성한다 | 1 질문 수집 인터뷰 | 상상한 질문이 아니라 반 친구 실제 질문으로 시작 |
| | | 2 엔트리 텍스트 분류 챗봇 | 의도 분류 모델 + 답변 블록. 생성형 AI 계정 없이 챗봇 원리 체험 |
| | | 3 챗봇 괴롭히기 테스트 | 줄임말 · 오타 · 사투리 공격으로 오답 수집 후 보강 |
| 고 (4×50) | 지시문 · 참고 자료를 넣은 챗봇을 만들고 20문항 평가표로 개선 전후 정확도를 비교한다 | 1 세 챗봇 블라인드 비교 | 지시문 없음 · 역할만 · 자료까지 넣은 AI를 이름 가리고 채점 |
| | | 2 시스템 지시문 설계 | "모르면 모른다고 답하기" 같은 금지 규칙까지 직접 씀 |
| | | 3 레드팀 시험 | 다른 모둠이 규칙을 깨려는 질문을 던지고 막지 못한 것 기록 |
| | | 4 평가표 측정 시연 | 감상 발표 대신 정확도 · 근거 제시율 숫자로 시연 |
| 대 (6시간) | 학과 · 동아리 반복 문의를 처리하는 챗봇을 사용자 5명 이상 테스트 후 배포한다 | 오전1 문의 로그 수집 / 오전2 지시문 · 지식 자료 설계 / 오후1 현장 사용자 테스트 / 오후2 배포와 운영 규칙 | 실제 사용자 로그와 테스트로 완성 판정 |

도구 메모: 중등 엔트리는 모델 학습에 로그인 필요 → 교사가 학급 계정을 미리 생성(안 되면 1차시가 가입으로 소모). 고등은 Gemini Gems 등 무료 맞춤 챗봇 기능(만 14세 이상 본인 계정 또는 학교 계정, 18세 미만 보호자 동의). ChatGPT 맞춤 GPT 만들기는 유료 기능이라 기본 도구에서 제외.

## 6. ai-prompt — 프롬프트 실험실 (genai)
컨셉 한 줄: 프롬프트 팁을 외우지 않고, 조건 한 칸씩만 바꾸는 실험으로 "무엇이 결과를 바꾸는지"를 찾아 레시피로 남긴다.

| 대상 | 학습목표 | 차시 · 훅 | 왜 뻔하지 않은가 |
|---|---|---|---|
| 초 (2×40) | 대상 · 배경 · 색 · 분위기 4칸 주문서를 쓰고, 한 칸씩 바꿀 때 그림이 어떻게 달라지는지 비교한다 | 1 말로만 그리기 게임 | 친구 설명만 듣고 그려 보며 "정확한 주문"의 조건을 먼저 몸으로 찾음 |
| | | 2 그림 AI 주문서 대작전 | 학생은 주문서를 쓰고 교사가 입력(계정 없음). 한 칸만 바꾼 4장 비교 |
| 중 (3×45) | 역할 · 예시 · 형식 · 제약 4가지 조건을 바꿔 실험하고, 채점표로 가장 효과적인 조합을 찾는다 | 1 프롬프트 블라인드 시식회 | 답 4개를 이름 가리고 채점한 뒤 좋은 답의 조건을 거꾸로 찾음 |

## 뻔함 블랙리스트 점검
포스트잇 브레인스토밍, 마인드맵, 포스터 · 표어, 골든벨 · 카훗, PPT 조사 발표, 4컷 만화, 모둠토의 → 대표발표: 핵심 활동으로 쓴 차시 없음. 기존 ai-literacy 고등의 "AI 사용 원칙 선언문"은 실험(탐지기 오판률) 뒤의 표기 가이드로 바꿨고, 기존 ai-how 고등 "개선 방안 발표"는 숫자 근거가 있는 제안서 + 동료 검토로 바꿨다.

## 비판 검토 메모 (남은 위험)
- 엔트리 학급 계정 생성 방식과 Gemini 무료 Gems 생성 가능 여부는 수업 확정 전에 공식 안내로 재확인.
- Survival of the Best Fit은 결과가 스크립트로 고정돼 있어, "실제 AI가 이렇게 학습한다"로 오해하지 않도록 2차시 편향 역추적에서 실제 데이터 표와 구분해 다룬다.
- 고등 ai-literacy 1차시 가짜 뉴스 카드는 실존 인물 · 학교 · 기관을 소재로 쓰지 못하게 하고, 수업 뒤 파일을 회수 · 삭제한다.
- 초등 ai-prompt와 conv-reading 초등(AI 그림책)은 모두 그림 AI를 쓰지만, 이쪽은 조건 변인 실험, 저쪽은 책 장면 표현으로 목적이 다르다.
