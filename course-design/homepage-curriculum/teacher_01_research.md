# teacher 01 — 자료수집 · 분석 (교원 연수: ai-class / guidance)

조사일: 2026-11-24. 웹 검색 결과 요약 기준. 날짜·수치는 출처 표기된 것만 기록했다.

## 1. 정책 · 현장 동향

### AI 수업 활용 (ai-class)
- **AI 디지털교과서 → 교육자료**: 2025년 3월 '교과용 도서'로 도입된 AIDT는 2025년 8월 4일 초·중등교육법 개정안 국회 통과로 '교육자료'가 됨. 구독·사용 여부를 학교가 예산과 판단으로 정하는 구조로 바뀌어, 교원 연수 수요가 "특정 플랫폼 사용법"에서 "교사가 고르고 설계하는 AI 수업"으로 이동. (연합뉴스 https://www.yna.co.kr/view/AKR20250804112000530 , 교육을비추다 https://www.kyobit.com/news/articleView.html?idxno=3879)
- **수행평가 AI 활용 관리 방안 (교육부, 2025-12-23)**: 일률 금지 대신 ①교사가 평가 전 과목별 AI 활용 범위 기준 설정 ②학생에게 AI 활용 과정·출처 표기 지도 ③수업 중 실시간 관찰 중심 평가로 신뢰성 확보. → 연수에서 "AI 사용 허용 수준표 + 사용 표기 양식 + 관찰 체크리스트"를 직접 만들게 할 근거. (https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=104984&lev=0&m=020402)
- **평가원 연구리포트 제13호 (기사 2026-10, 2025년 연구)**: 교사 약 63%가 수업·평가에 생성형 AI 활용. 아이디어 구상·자료 개발·형성평가 문항 제작은 많고, 학습자 분석·루브릭 채점 보조는 적음. 가이드라인: AI 생성 문항은 교사가 검토, 학생은 AI 사용 전 스스로 생각할 기회, AI 결과와 사고 과정·성장을 함께 평가, 기기·계정 없는 학생용 대체 자료 마련. (https://www.kyobit.com/news/articleView.html?idxno=7592)
- **초등 가이드라인 논쟁 (2026-10)**: 전교조 조사 초등 4~6학년 72%가 생성형 AI 사용. "활용법보다 선 긋기 먼저" — 학생 직접 사용 / 교사 시연 / 교사 업무용을 나눠 기준을 세워야 한다는 현장 요구. 경기도교육청은 교사용·학생용 가이드라인을 나눠 발간. (https://news.eduhope.net/28757)
- **개인정보**: 교육부·시도교육청 가이드라인은 학생 정보 비식별 입력 원칙을 공통으로 강조. (https://gyopool.com/blog/school-ai-privacy-guidelines)
- **학생 연령 제한**: ChatGPT 약관 13세 미만 사용 불가, 18세 미만 보호자 동의 필요. Gemini는 만 13세 미만은 Family Link로 부모가 관리해야 사용. 국내 개인정보보호법상 만 14세 미만 개인정보 처리는 법정대리인 동의 필요. → 초등·중1 수업은 교사 시연 또는 계정 불필요 도구가 기본. (https://support.google.com/gemini/answer/16109150?hl=ko , https://blog.naver.com/obafgkim/223415101779)

### 진로 · 학업 지도 (guidance)
- **고교학점제 전면 시행(2025~)**: 과목 이수 기준 = 수업 횟수 2/3 이상 출석 + 학업성취율 40% 이상. 기준 미도달 예상 학생에게 **최소 성취수준 보장지도**(예방지도·보충지도) 운영이 교사 책무로 들어옴. (교육부 블로그 https://m.blog.naver.com/moeblog/223596924708 , 인천교육청 https://www.ice.go.kr/hakjeom/cm/cntnts/cntntsView.do?mi=12755&cntntsId=1218)
- 교사 역할은 "진단 → 피드백 → 보충 → 재도전 루트를 설계하는 사람". 현장 연구는 업무 부담·진단 문항 부족을 가장 큰 어려움으로 꼽음. (에듀프레스 https://www.edupress.kr/news/articleView.html?idxno=20687 , 교육과정연구 https://www.ejce.org/archive/view_article?pid=jce-27-4-25)
- **과목 선택 상담**: 교육부가 과목 선택 집중 상담(컨설팅) 기간 운영. 인천교육청 진로·학업 설계 지도 자료는 상담을 과목 선택 상담 / 학습 설계 상담 / 학습 관리 상담으로 구분. (https://blog.naver.com/moeblog/223911121256 , https://www.ice.go.kr/upload/hakjeom/na/bbs_1571/2025/03/a6c69211beedd1ab6d9ae599d5b260e2.pdf)
- **2026 고교 진로·진학 상담 역량 연수**(교육부·한국과학창의재단, 진로전담교사 대상): 현직 교사·대학 전문가가 함께 집필한 '진로·진학 상담 안내서'를 바탕으로 진행. (https://hangyo.com/mobile/article.html?no=108826 , https://happyedu.moe.go.kr/happy/bbs/selectBoardArticleInfo.do?bbsId=BBSMSTR_000000000231&nttId=14714)

## 3. 흔한 패턴 (피할 것)
1. **도구 나열식 시연**: "AI 도구 5종" 식으로 화면 시연 후 각자 해 보기. 교사는 집에 가서 무엇을 바꿀지 모름.
2. **정책·제도 해설 강의**: 고교학점제·가이드라인 조문 설명이 1시간 이상. 상담·문항 제작 실습 없음.
3. **시청 = 참여**: 출석률·퀴즈로 이수 처리. 동료 피드백, 현장 적용 과제 부재.
4. **결과물이 연수용 작품**: 교실에 다시 들고 갈 형식(차시안·양식·문항)이 아님.

## 4. 빌려올 메커니즘 (5개)
1. **사례 1개 = 결과 1개 마이크로 모듈** (Google AI Educator Series): 각 모듈 끝에 "다음 날 쓰는 결과물 1개"를 남긴다. 3시간 특강도 모듈 3개 = 결과물 3개.
2. **내 단원 하나로 끝까지** (클래스똑 프로젝트형): 도구를 따로 배우지 않고, 선생님이 가져온 단원·편성표·과목 하나를 고쳐 가며 도구를 필요할 때 쓴다.
3. **동료가 학생 역할** (지식샘터 + 마이크로티칭): 설계한 활동·상담을 동료 3인 조에서 10분 시범으로 돌리고 교차 피드백.
4. **적용 후 회고 순환** (Stanford CRAFT): 15시간 직무연수는 모듈 사이에 현장 적용 과제를 두고, 마지막 모듈에서 실제 결과로 자료를 다시 고친다.
5. **연수와 학생용 자료를 짝으로** (Common Sense): 교사 연수 결과물이 곧 학생에게 나눠 줄 규칙·양식·수업안이 되게 한다.

## 5. 설계 시사점
- 교육부 2025-12 관리 방안 → "AI 사용 허용 수준표 + 사용 표기 양식 + 관찰 체크리스트"는 ai-class 수업·평가 연수의 핵심 산출물.
- 초등 선 긋기 요구 + 연령 약관 → 학생 AI 사용 지도 연수는 '학생 직접 / 교사 시연 / 교사 업무용' 3분류를 축으로.
- 최소 성취수준 보장지도의 실제 부담은 "진단·보충 문항 제작"과 "운영 일정" → AI는 변형 문항 초안에, 교사는 검토에.
- 상담 연수는 실제 학생 정보를 AI에 넣지 않도록 가상 사례 카드만 사용.
